✓Exact matching
Exact matching asks Facebook to be much stricter about matching your query, but often ends up excluding real results. It's useful for if you want fast results, but in general, it's better to leave it off.

Cities

The search reaches out from each selected city as far as your Facebook radius setting allows — up to 500 miles. Select all cities and set your radius to 500 miles to get search results from the entire continental US.
Cities you add are saved locally, and you can remove them by hovering over them.
How to get a city's link
  1. Open facebook.com/marketplace in your browser.
  2. Click the location on the left sidebar — it shows whatever city you're currently browsing.
  3. Type the city you want, pick it from the list, set the radius you want (500 miles is as far as Facebook goes), and click Apply.
  4. Copy the whole web address out of the address bar and paste it in the box above. It looks like facebook.com/marketplace/denver/... — the part right after "marketplace" is what this needs, and it's fine if it's a long number instead of a name.

Leave the name box blank and it'll name the city after that link.

✓Dump raw payloads
Dump raw payloads saves the raw JSON Facebook sent into the run folder's debug/. Only useful for troubleshooting. For example, if titles or prices start coming back empty, that means Facebook changed the shape of its data, and the dump is what you'd inspect to fix it. It's bulky — roughly 8 MB per city — so leave it off normally.

Email

Reports are sent from your own email account. For Gmail you need an app password, not your normal password — see the steps below. An app password gives this tool full access to that mailbox, so it's stored in .state/email_config.json, which is kept out of version control.
How to get a Gmail app password
  1. Go to myaccount.google.com and sign in.
  2. Open Security & sign-in in the left sidebar.
  3. Turn on 2-Step Verification if it isn't already. App passwords don't work without it.
  4. Search that page for App passwords and open it.
  5. Type a name like Faceplace Marketbook and click Create.
  6. Google shows a sixteen-letter password. Copy it into the box above. You can include the spaces or leave them out.

Because you're sending to yourself, Gmail may file the report under Sent Mail instead of your inbox — look there too. Sending reports to a different address avoids this.
